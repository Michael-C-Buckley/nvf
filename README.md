# NVF Flake

This is my customized Neovim setup via [NVF](https://github.com/NotAShelf/nvf).

NVF is a Neovim framework in Nix.
It trivialized creating and maintaining a custom nvim setup.

I have tried a few other mechanisms and I think it is the best, just because it gives the assurances
that nix provides and makes breakages and package management a lot easier.
